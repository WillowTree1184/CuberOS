# CuberOS

A coding adventure of building an operating system.

# Environment

Make sure that you have the following installed:

- make
- qemu (qemu-system-x86_64)
- ovmf (OVMF_CODE_4M.fd, OVMF_VARS_4M.fd)
- clang (clang, lld-link)

# Quick Start

Run the following command to build and run the operating system:

```bash
make run
```
